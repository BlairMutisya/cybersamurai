Idempotent consumer with bounded retry classification

The example separates a durable idempotency claim from business processing and deliberately avoids retrying validation failures.

PaymentEventConsumer.java
@KafkaListener(topics = "payment.events")public void consume(PaymentEvent event) {  if (!claims.tryClaim(event.id())) return;  try {    payments.apply(event);    claims.markCompleted(event.id());  } catch (ValidationException invalid) {    claims.markRejected(event.id(), invalid.getMessage());  } catch (TransientIntegrationException retryable) {    claims.release(event.id()); // bounded retry may reclaim    throw retryable;  }}
